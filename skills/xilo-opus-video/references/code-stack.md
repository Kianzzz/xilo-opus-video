# 代码类型和组合

选技术的原则：**先定画面风格，再选能做出这种风格、最简单的那一种代码**。能用一种做完就不要混三种；要混的时候，按「内容层 → 质感层 → 声音层」叠，每一层单独能跑、单独能检查。

## 八种代码

| 代码 | 擅长 | 典型画面 | 不适合 |
|---|---|---|---|
| Canvas 2D | 一笔一笔画的二维画面 | 像素风、扁平插画、手绘线条、粒子、图表 | 大量需要清晰排版的文字（放大会糊，要按设备像素比设画布尺寸） |
| HTML / CSS / SVG | 界面和文字 | 界面动效、大字排版、卡片、数据图表、图标描边动画 | 成千上万个粒子、复杂质感 |
| WebGL 着色器 | 每个像素单独算颜色的质感 | 老电视弧面和扫描线、胶片颗粒、网点、水面反光、光晕 | 直接画内容（一般先用 Canvas 画内容，再送进着色器） |
| Three.js | 3D 场景 | 产品转台、3D 文字、点云、低多边形场景、体素世界 | 写实人物 |
| p5.js + p5.brush | 手绘笔触 | 彩铅、水彩、蜡笔绘本 | 需要很快渲染的长片（笔刷很慢，先测单帧耗时） |
| GSAP / HyperFrames | 时间轴动画、快节奏动效短片 | 发布会风格、卡点动效 | 用户没装也没点名的时候不要主动引入 |
| Remotion（React） | 长片、多场景、需要读产品代码库 | 产品宣传片、知识讲解、历史回顾类短片 | 一次性的十几秒小动效（单个 HTML 更快） |
| Manim（Python） | 数学和原理讲解 | 公式推导、坐标轴、图形变换 | 设计感强的品牌动效 |

声音层：配乐和音效用 Python（numpy / scipy）从零合成，或者用用户提供的音乐；配音接语音模型（edge-tts、Kokoro，或用户自己的付费语音），整段合成。

## 默认选择

- 用户没点名：**单个 HTML 文件 + render(t)**，内容用 Canvas 或 HTML/CSS/SVG，需要质感再加一层 WebGL。
- 用户有产品代码库、要多场景长片、或者点名 React：Remotion。每个场景一个组件，动画全部用当前帧号算。
- 用户点名 HyperFrames：先安装它的 skill（`npx skills add heygen-com/hyperframes`），按它的规范写。
- 数学、物理、算法讲解：Manim，渲染不走浏览器，用 Manim 自己的命令出视频，再用 FFmpeg 混声音。

## 风格 → 组合速查

| 想要的效果 | 组合 | 参考的公开案例（学手法，不照搬） |
|---|---|---|
| 像素动画 | Canvas 2D 小画布（如 128×96）整数倍放大 + 姿势按 8–12fps 量化 | @majidmanzarpour 的像素巫师 |
| 高级感界面动效 | HTML/CSS/SVG + 闭式弹簧 + 节拍网格 + 4 子帧运动模糊 + 合成界面音效 | @twoclipping 开源的界面变形模板 |
| 动效作品集 / 片头 | HTML 大字排版 + SVG 手写标注 + Canvas 粒子 + 合成音效 | 「15 秒动效作品集」一句话提示词的一批作品 |
| 复古游戏 / 老电视 | Canvas 像素内容 → WebGL CRT 着色器（弧面、扫描线、荧光点、光晕） | @prasenx 的游戏史短片 |
| 年代跨度大的历史片 | 每个年代换一种画法：Canvas 像素、着色器质感、Three.js 3D，统一配乐贯穿 | @prasenx 的游戏史短片 |
| 知识叙事长片 | Remotion + SVG/Canvas 场景 + 一个贯穿全片的视觉主角 + 旁白 + 合成配乐 | @kimmonismus 的 AI 发展史 |
| 产品宣传片 | Remotion 或 HTML + Playwright 实拍产品网页截图并记录元素坐标 + 镜头推到真实按钮上 | @aiwarts 的 GoodCase 宣传片 |

## 视频模型角色 + 代码场景

代码画不好写实人物和复杂的舞蹈动作。这时候让视频模型只负责人物，其他全部用代码：

1. 用户用视频模型（Grok、即梦、可灵、Seedance 等）生成人物片段，**要求纯绿色背景**，人物全身入镜、不要出画。
2. 抠像：`ffmpeg -i dancer.mp4 -vf "chromakey=0x19FF0A:0.16:0.08,despill=type=green" ...`，颜色值用抽帧里绿幕的实际颜色；先抠一帧给用户看边缘。
3. 背景、大字、贴纸、分屏、3D 环绕文字用代码做成一层视频（render.py 渲染）。
4. 用 FFmpeg `overlay` 把人物叠上去；分屏就是同一段人物错开几帧叠多次。
5. 节拍：分析音乐节拍，背景和大字每一拍变一次，人物片段本身不用改。

公开案例：@Gorden_Sun 的甜酷舞蹈（Grok 绿幕人物 + 网页动效背景）、@AbaneChan 的股票主题自我介绍（Grok 生成三段舞蹈 + 作品集提示词）。
